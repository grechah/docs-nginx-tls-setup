## Задача

DOCUM-0000 — добавить в руководство администратора раздел о настройке HTTPS на Nginx с reverse proxy для backend-приложения.

## Что сделано

Добавлена новая страница `docs/admin-guide/nginx-https-reverse-proxy.md`:

- prerequisites с таблицей проверок окружения;
- пошаговая инструкция: установка Nginx, выпуск самоподписанного сертификата через openssl, настройка server block с TLS и `proxy_pass` на `127.0.0.1:8080`, проверка результата;
- Mermaid-диаграмма прохождения запроса «Клиент → Nginx :443 → Backend :8080»;
- таблица из 17 параметров конфигурации с назначением каждой директивы;
- раздел Troubleshooting: 502 Bad Gateway, занятый порт 443, ошибка загрузки сертификата или ключа.

Также добавлены `README.md` и `.gitignore` для репозитория документации.

## Как проверить

1. Собрать документацию локально и открыть страницу: `npm run build && npm run serve`.
2. Убедиться, что Mermaid-диаграмма и обе таблицы отображаются корректно.
3. Пройти инструкцию на тестовом стенде с backend на порту 8080 и проверить, что команды выполняются без правок.

## Открытые вопросы

- Плейсхолдеры `[Screenshot: ...]` нужно заменить реальными скриншотами со стенда.
- Уточнить у команды эксплуатации, нужно ли добавить вариант с сертификатом Let's Encrypt отдельным разделом или отдельной страницей.
- Подтвердить перечень поддерживаемых дистрибутивов: сейчас примеры даны для Ubuntu 22.04 и Debian 12.
